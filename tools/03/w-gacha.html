💡 このガチャについて

名言は Quotable API、ジョークは Chuck Norris API から取得します。 取得した英語の文章は、APIキー不要の MyMemory Translation API を使って 日本語へ翻訳します。

翻訳APIが利用できない場合でも、名言そのものは表示できるようにしています。
